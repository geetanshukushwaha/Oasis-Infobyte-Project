📄 Number Guessing Game (Java)
A simple console-based Java application where the computer generates a random number between 1 and 100, and the player attempts to guess it within a limited number of attempts. The system provides feedback whether the guess is too high, too low, or correct.

📌 Features
Random number generation between 1 and 100.

User-friendly console input.

Feedback on each guess (too high, too low).

Limited number of attempts (configurable).

Displays the number of attempts taken on success.

Game over message if attempts are exhausted.

🛠️ Technologies Used
Java SE (Standard Edition)

Scanner class for user input

Random class for number generation
